## 关键语义

**本地取消与外部完成分别记录。** 模型取消会立即结束本地 `await`，未合作的提供商 Promise 仍占据唯一上游槽位，直到它真正结束。设备取消保留 `cancel-requested` 或 `unknown`，不会把 `AbortSignal` 解释成副作用已撤销。

**迟到模型结果不执行，迟到设备结果要对账。** 设备回执仍关联旧轮次。用户改口后旧保存可能实际完成，但它不能凭旧目标版本完成新任务；新的目标只认重新观察后的真实字段。

**重置不能掩盖未决执行。** `reset()` 先暂停并尝试取消所有通道；设备尚未确认时保留旧 epoch 和记录、抛出 `unsettled_operation`，同时停止其他身体和输出。完成查询/对账后才能清空状态。

**时间口径分开。** 同步 `ActionRuntime.elapsedSeconds` 是实际运行的模拟时间；异步设备的同名字段是单调时钟计算的真实持续时间，包含设备等待。UTC 用于显示与关联，时钟校准不会提前耗尽冷却或延长操作期限。

**资源检查是执行前校验。** 冲突组合在产生效果前拒绝，但这不构成跨设备事务。已经产生的效果不会因后续通道失败而自动回滚。

**表现与任务事实分开。** 倾听、思考和欣喜可以通过已声明的非语言反应通道触发。它们不算任务回执。Home 原生语音保持整段文本/转写校验，当前嘴部动画只根据播放状态变化，不是经过验收的音素级唇形同步。

## 体验与接入

```sh
# 仓库根目录
pnpm dev:computer       # 本地规则 + 真实浏览器，http://127.0.0.1:3110
pnpm dev:computer:live  # 显式使用配置中的 JEV + LLM
pnpm dev:home           # 原有家园，包含新表情/视线
```

Computer 启动和模型配置见 [应用说明](../apps/realtime-computer/README.md)。内核类型和约定见 [Agent README](../packages/agent/README.md)。本轮继续使用工作区锁定的 `@system-one-ai/sdk@0.5.2`，没有同时进行 SDK 包迁移。

新增领域应提供观察、候选、能力和目标验证器，再注册到同一 Agent。设备使用异步通道；本地游戏技能可以使用同步通道。需要多个 Agent 控制同一设备时注入同一个 `ResourceArbiter`。`TaskLedger` 由宿主持有，语言模型提议转换成已注册技能，逐步获批后才分发。

Home 表现用例通过真实 UI/API 发送任务与规划输入，同时验证服务端通道、执行归属与 canvas 表现属性，随后检查暂停、重置恢复默认态。浏览器与单测的覆盖范围不同，不能把规则闭环通过当成真实 JEV/LLM 成功率或成本基线。

本轮发现并修复的实际问题：浏览器采集函数被 TS 转换器注入 `__name` 后无法在页面序列化执行；旧模型真正结束后 Home 未重新唤醒最新输入；模型取消仍等待截止时间；未发送操作触发设备取消钩子；取消回调中的同步终态被重复通知；审核期间更新的感知未再次检查；未决设备重置留下其他活动；墙钟变化影响冷却；计划过期后未重新规划。

独立打包脚本另修复 Windows `.cmd` 入口无法直接 `execFileSync` 的问题，改为通过 Node 执行包管理器 CLI 和参数数组。测试成功报告在 `test-results/agent-package/verification.json`。

截图：`test-results/computer/{desktop,mobile}.png`。这组截图来自最初通过的浏览器轮次；之后将演示模式的指标名改为“本地决策 P95”，避免误称为 JEV 性能。该单行文案修正通过 JS 语法检查。

Home 截图位于 `apps/realtime-home/test-results/presentation/01-listening.png` 至 `05-reset.png`；本轮查看了思考和暂停画面，以及 Computer 桌面/手机截图。动画语义由运行时与 canvas 属性的浏览器断言验证，截图本身不证明帧率或音素同步。

## 后续阶段

P0 已具备有限时序与模型用量观测，尚未完成真实模型、真实网络和多任务分布的成本/成功率基线。P1 的核心协议和 P2 的受控浏览器、轻量任务、Home 基础表现已交付。

P3 仍需 Windows 原生可访问性/键鼠驱动、动态游戏参考环境，以及跨进程执行日志和崩溃恢复。当前 DOM 观察不是截图视觉模型，不能宣称任意网站、任意游戏或全桌面支持。

P4 仍需在相同感知、能力和任务分布下比较 JEV-only、LLM-only、双系统，以及多 Agent 共享设备测试和 SDK 发布验收。设计中的 500 ms 响应、60 FPS、100 ms 停止等均未在本轮成为性能承诺。
