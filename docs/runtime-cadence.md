# Home 自主行为与一秒调度修复

日期：2026-09-18。范围为默认应用 `apps/realtime-home`；未修改另一个 demo 应用的行为策略。

后续实时对话在保留一秒自主 tick 与一秒最短请求间隔的前提下，为用户输入和对话回复增加及时唤醒，并在新意图评估时暂缓旧动作。本文的“统一等下一 tick”描述保留为当次修复记录；当前交互时序见 [实时对话与阶段验证](realtime-conversation.md)。

## 原因与复现

使用现有根目录 `.env` 真实请求 Jev，修复前在无用户指令时得到过 `water / confidence=0.28`，需求耗尽时得到 `read / confidence=0.13`。两次都是 HTTP 200 且返回合法候选。运行时却因置信度低于 0.55 直接返回，推进世界后仍为零动作、零完成，而需求继续下降。

原测试覆盖了明确指令，没有覆盖无人指挥的自主生活。提示中的“maintain hydration below 55”也容易混淆满足度方向，已改为低于阈值时恢复需求，并明确高数值代表更满足。所有实际动作仍由 Jev 选择。

## 执行与调度

合法、可达且未过期的生活动作进入寻路、行走、交互和结算。置信度保留展示，不再作为可逆生活动作的硬性执行门槛。已承诺的动作不会因为下一次普通 tick 重启；切换动作前先校验新路径，Jev 未批准中断则继续当前动作。

物理模拟每 100 ms 推进、状态每 200 ms 广播，决策使用独立的一秒 tick。新消息、动作完成、需求跨入紧急区间和慢思考返回仅标记待处理事件。事件合并后在下个 tick 评估，请求开始间隔至少一秒。执行期间没有新事件时不发请求；模型选择等待后五秒再观察，新的消息可在下个 tick 唤醒。

请求尚未结束的 tick 被跳过，不积压任务。取消后等待 Promise 结束才释放并发槽，暂停恢复、重置和倍速均不能绕过限速。提供商的错误退避继续生效。

界面新增当前执行阶段、交互进度、已完成动作数和调度说明。断线时明确显示最后已知状态，并停止在旧快照上播放生活动画。SSE 的订阅清理绑定响应连接关闭，增加了收到初始快照后继续接收后续变化的回归验证。

## 真实自主运行样本

两项新增测试使用真实 `jev-latest`（响应 `jev-1.13.0`），没有插入用户指令或替换模型选择：

| 场景 | 结果 |
| --- | --- |
| 浏览器打开后不发消息 | 自主完成喝水、浇水；最后一次浇水置信度 0.46 也正常执行；约 10.6 秒通过 |
| 独立世界，水分 0、饱腹 2、精力 0 | 在相同生产调度器中，以 4× 模拟速度完成喝水、喝水、睡觉、吃饭；约 16.6 秒通过 |

恢复场景用了 **16 次调度 tick、4 次 Jev 请求、4 次完成动作**，无中断或错误。最后一轮结尾需求约为水分 **71.38**、饱腹 **33.91**、精力 **39.91**；这都是执行器在真实模型选择之后结算的世界值。四次请求开始间隔约为 3 秒、2 秒、6 秒，动作执行期间跳过了无事件的请求机会。

普通自动化新增受控时钟测试，验证一秒边界、消息合并、倍速独立、动作承诺、取消期间单并发、暂停/重置限速、错误退避、等待慢思考和主动等待周期。现有模型解析、路径、动作效果与中断断言保留。

复查发现自主补水描述可能干扰“先只聊天、不行动”的用户请求，因此将有用户指令与无指令自主生活的决策说明分开，前者明确优先满足用户约束。真实对话测试增加了零启动动作、零完成动作断言，最后一轮实际为 2 次 Jev 请求、1 次 DeepSeek 请求、0 次动作启动。

本轮 Home 验证：**41 项普通自动化测试、3 项普通浏览器测试通过；最后一轮 5 项真实模型场景连续通过，耗时 52.5 秒；TypeScript 检查和生产构建通过。** 三个原有真实场景为单步喝水、Jev 请求并采纳 LLM 对话、顺序喝水/浇水及睡觉中断。Three.js 既有体积提示仍保留。
