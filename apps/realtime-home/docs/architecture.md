# RealtimeAgent v0.1 架构

2026-09-18 更新：新的独立内核与迁移契约见 [Agent 架构设计](../../../docs/agent-architecture.md)。Home 的轮次、模型调度、慢思考和动作协调已由 `@realtime-agent/agent` 的 Agent 统一管理；能力执行位于 `server/agent-environment.ts`，人格、存储与 UI 指标通过宿主策略和事件接入。所有说话通过慢模型提议 → Jev 采纳并选择 speak → 输出执行器；原生音频只渲染获准原文并校验转写；下文中的节奏与领域行为仍保留。

## 行为闭环

```text
用户对话 / 家具请求 / 世界事件
              ↓
权威世界快照 + 当前意图 + 可执行候选动作 + 近期真实结果
              ↓
       快系统（live = Jev）
        ├─ Choice：下一步动作
        ├─ Noul：是否中断
        ├─ Noul：是否需要慢思考 ─→ LLM：计划、回复、记忆建议
        ├─ Noul：指令是否已完成              ↓
        └─ Choice：采纳 / 拒绝建议 ←─ 绑定意图版本的建议
              ↓
版本 / 动作白名单 / 前置条件 / 路径检查
              ↓
      寻路 → 行走 → 执行动作 → 验证效果
              ↓
      更新真实结果、需求与经历记忆
              ↓
         下一轮事件驱动决策
```

前端以 SSE 接收服务端快照，并做位置和动画插值。服务端每 100 ms 推进物理时间，每 200 ms 广播状态；另有独立的 **1,000 ms 自主决策 tick**。动作完成、单项需求跨入紧急区间、自主思考返回标记需要重评。用户新消息和对话回复返回可唤醒同一个调度器，不必额外等到下个固定 tick；40 ms 合并窗口与一秒最短请求间隔同时生效。没有新事件时不会反复请求模型；模型选择等待后，五秒再观察。

用户输入先记录服务端收据、轮次与客户端序号，取消旧请求，并将当前动作置于 `attending` 暂缓状态。角色位置和交互进度保持，Jev 返回有效选择后继续、停止或从实际位置改走新路径。插话取消只针对原世界和原轮次，不授权新的物理动作。消息、行为应用和已采纳回复的时间记录在 `WorldState.turns`；详见 [实时对话与验收](../../../docs/realtime-conversation.md)。

每次请求开始至少相隔一秒，2×/4× 只加速模拟时间。请求未结束时跳过 tick，不排队、不补发。取消请求后仍占用并发槽位直到 Promise 结束；重置和暂停恢复不绕过请求间隔或提供商退避。`WorldState.scheduler` 提供调度状态，决策 trace 的 `requestedAt` 用于核对实际请求间隔。

## 运行时约束

`version` 是影响决策的语义版本，不随每一帧坐标变化递增。快系统结果必须仍匹配发起时的 `epoch` 和 `version` 才能生效。新意图更新 `intentVersion` 并取消正在进行的快慢请求。

慢思考绑定 `epoch` 和 `intentVersion`，允许世界在它思考时继续推进；新指令、重置、暂停或超过返回期限会使结果失效。返回值只是建议，不会调用动作执行器。快系统采纳的偏好以“建议”保留，与已执行的经历区分。

动作先寻路并抵达交互点，再计执行进度；完成后应用效果并写入 `Outcome`。未完成的动作被中断时不授予效果。动作有 120 模拟秒的承诺上限，超时会取消。下一步仍由快系统决定，运行时不会自动执行 LLM 返回的动作列表。

本世界的候选是可逆的生活动作，通过版本、候选集合、前置条件与路径校验即可执行。Choice 置信度保留用于观察，**不再以固定 0.55 门槛阻止动作**；多个合理选项导致分布分散时也必须能行动。是否调用 LLM 仍仅由 Jev 的 `think` 判断触发（阈值 0.7）。中断阈值为 0.7，请求完成阈值为 0.8。建议通过独立 Choice 问题选择采纳或拒绝，并校验来源，不附加置信度门槛。新增涉及不可逆外部操作的能力时，需要另行设计执行授权，不能直接沿用生活动作策略。

慢思考最多并发一次，同一意图的两次开始至少相隔 15 秒。新的用户消息会取消旧请求并清除旧意图的冷却期，仍需快系统选择是否再次思考。Jev 请求超时 10 秒，LLM 超时 30 秒，响应体限制 128 KiB。429 等错误考虑 Retry-After，决策错误使用有上限的指数退避。执行新的行为不会依赖模型自行声明的“已经完成”。

## 模型边界

TypeSafe 请求使用 `model=jev-latest`，由环境变量覆盖。`choice` 答案的 `confidence` 与最高选项的概率分开保存；响应必须满足类型、候选键集合和概率分布约束。

LLM 不能修改世界对象、修改资源值、读取密钥或调用执行器。返回的动作 ID 需要通过有限枚举校验。记忆建议会保留为 `source=reflection`，经历由执行结果生成并标为 `source=experience`。

外部服务的错误响应可能包含回显的密钥或请求内容，因此不向浏览器转发原始响应体。配置状态与真实 API 调用结果分开：配置存在不保证服务可用，真正的调用失败出现在事件记录与提示中。

## 后续扩展

人格与生活记忆已经接入此闭环：相关经历、个人愿望、兴趣倾向和心情进入快慢系统观察；处理明确当前任务时，快系统使用隔离的任务完成记录，避免过去经历和个人愿望冒充这次任务。两次实际经历可构成自主反思机会，Jev 选择是否调用。自主反思最短间隔 90 秒真实时间，返回的自述必须引用实际经历，经 Jev 明确选择采纳后才写随记或产生新愿望。普通对话不生成额外随记。未获采纳的建议 60 秒过期后释放位置。详细状态、持久化与边界见 [生活记忆说明](../../../docs/inner-life.md)。

有限的连续改令、停止和实时文字对话已加入真实账户验证，第一阶段仍需完成语音设备与识别链路验收，并扩大矛盾指令、复杂计划、环境变化和失联恢复样本。记录正确率、动作完成率、端到端延迟和单位时间调用数后，再根据证据调整调度。

进一步的产品化工作包括：每用户独立世界与权限、持久化世界及任务恢复、事件增量传输、可回放轨迹、可组合技能与复用条件、端到端实时音频模型接入、导航障碍动态更新及更细腻的动作动画。这些不包含在本轮 Demo 的实现声明中。
