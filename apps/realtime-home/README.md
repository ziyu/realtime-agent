# RealtimeAgent

一个实时运行的 3D 家园实验：Milo 在客厅、厨房、卧室和书房里生活，你可以通过对话或点击家具改变它的行为。

架构约定：**Jev 选择所有身体行为，并决定日常慢思考的调用；原生语音通话由音频模型持续听与说，最终转写交给 Jev。动作效果始终由服务端世界执行和验证。**

新增原生音频会话：OpenAI Agents SDK 浏览器 WebRTC 直连，以及 LiveKit Agents 下的 OpenAI、GPT-Live、Gemini Live、Grok Voice。音频模型处理持续聆听与说话，最终转写交给 Jev 控制身体；旧浏览器识别成为明确选择的兼容选项。配置与限制见 [原生音频接入](../../docs/native-voice.md)。

## 启动

本应用是 pnpm workspace 中的 `@realtime-agent/home`，位于 `apps/realtime-home`。以下命令在本应用目录执行；也可从仓库根目录使用 `pnpm dev` 启动。依赖统一使用根目录的 `pnpm-lock.yaml`。

需要 Node.js 22.13+ 和 pnpm 11.1.2，版本由仓库根目录固定。

```sh
pnpm install
pnpm dev
```

打开 **http://127.0.0.1:5174**。世界服务默认在 `127.0.0.1:3102`，Vite 将 `/api` 转发给它。这两个端口独立于已经运行的其他 RealtimeAgent 实例。

未配置密钥时是**本地演示模式**，仍可体验场景、动作、聊天输入和事件流。演示使用明确标注的规则选择器和模拟慢思考，不调用任何模型。配置 System One 密钥后默认使用真实模式，显式 `AGENT_MODE=demo` 可覆盖这一默认值。

## 连接真实模型

在仓库根目录 `.env` 配置以下字段后重启服务。也可在应用目录使用独立 `.env` 覆盖根配置；优先级为进程环境 > 应用 `.env` > 根目录 `.env`。已有文件时保留现有密钥。

```dotenv
AGENT_MODE=live
SYSTEM_ONE_BASE_URL=https://api.typesafe.ai/v1
SYSTEM_ONE_API_KEY=your-typesafe-key
SYSTEM_ONE_MODEL=jev-latest

LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=your-llm-key
LLM_MODEL=deepseek-flash
```

Jev 直接调用官方 `POST https://api.typesafe.ai/v1/systemone`，使用 `state`、`model`、`questions`，其中 `choice.criteria` 是动作名称到描述的映射。建议评估同样使用 Choice 明确选择采纳或拒绝；中断当前动作、唤醒慢思考、请求是否完成使用 Noul。参考 [TypeSafe API](https://docs.typesafe.ai/api)。

慢思考使用兼容 Chat Completions 的 `POST /chat/completions` 和 JSON 输出。DeepSeek 官方端点使用 `max_tokens` 与关闭内部长推理的选项；其他端点使用 `max_completion_tokens`。支持根地址、`/v1` 基址或完整接口地址，具体以提供商为准；同一接口路径不会重复追加。旧的 `TYPESAFE_API_KEY`、`TYPESAFE_MODEL` 和 `JEV_MODEL` 仍可使用。

密钥仅由 Node 服务读取，不进入前端构建、SSE、运行记录或本地记忆。实时模式缺少 Jev 密钥会拒绝启动；调用失败会显示错误并退避重试，**不会自动降级为本地规则**。可以只连接 Jev，但它请求慢思考时会提示语言模型尚未连接。

## 体验路径

打开“内心”面板，可以看到 Milo 的性格、心情、当前心声、个人愿望和生活随记。它起初安静、好奇、喜欢照料绿植；兴趣倾向和新鲜感会随实际经历变化，身体状态仍需照顾。起初的愿望是明确的角色设定，之后的随记和新愿望来自模型对真实经历的反思，不伪造已有过去。

可以和它聊“你今天有什么自己的打算？”“为什么喜欢这样的生活？”“你还记得我的偏好吗？”。普通动作只更新执行状态，不再机械地往聊天里发送“收到、开始、完成”。“偶尔主动分享”开关只控制主动发言，关闭后仍会安静地反思，用户提问照常回答。记忆条目可以查看原话和遗忘。

即使不发送消息，Milo 也会自主选择生活动作。自主调度每秒 tick 一次；动作完成、紧急需求变化或自主思考返回时重新评估。新的用户输入和对话回复可以及时唤醒同一调度器，仍保持请求开始至少相隔一秒，不会并发或补发，2×/4× 不加快模型调用节奏。接收新输入后先保持动作位置和进度，Jev 判断后继续或切换。页面展示当前动作、执行进度、已完成动作数和每轮反应时间。

打开家园后，Milo 会观察需求并自主活动。输入“先喝水，再给植物浇水，最后看书”，观察路径、动作状态和实际需求变化；过程中输入“停止”或“去睡觉”体验新指令对行为的影响。

输入“帮我安排一下今天”，观察思考面板：快系统请求慢思考 → 建议返回 → 快系统评估 → 选择下一步。建议本身不能执行动作。

点击家具或打开“8 个可交互物体”，再点击“请 Milo …”。这也会转换成对话指令，由快系统决策，不绕过 Jev。

支持暂停、1×/2×/4× 模拟速度、相机旋转/缩放、重置家园、浏览记忆、导出世界状态和决策记录。文字输入支持 Enter 发送、Shift+Enter 换行、中文输入法组合键，可以在旧请求未结束时继续发送。改口会取消旧回复，旧 HTTP 响应也不会清空正在编辑的新草稿。

“开始实时对话”启用浏览器持续中文识别和回复朗读，说完的最终结果自动发送，中间转写只显示、不执行。插话会停止旧朗读并取消对应轮次的旧回复；“打断回复”也可手动取消。结束对话、暂停或断开连接会停止监听。语音使用浏览器能力，**不是端到端实时音频模型**，自然回复仍经 Jev 采纳后完整显示。建议使用耳机避免回声。设备与识别服务的实测范围见 [实时对话验证](../../docs/realtime-conversation.md)。

## 运行与验证

```sh
pnpm test          # 运行时、路径、模型 HTTP 契约、HTTP/SSE 测试
pnpm build         # 严格类型检查 + 前端生产构建
pnpm start         # 从 3102 提供 API 和已构建的前端
pnpm test:e2e      # 使用本机 Chrome 验证真实页面交互和 390px 布局
pnpm test:live     # 显式调用已配置的真实模型，会消耗额度
```

普通 E2E 只允许对 `demo` 世界执行，检测到 live 模式会停止。测试独占端口，每轮记忆写入独立的 `.test-data/` 子目录。`test:live` 使用真实模型，记忆隔离到 `.live-test-data/` 子目录。测试前停止同端口开发服务；结果均在被 Git 忽略的 `test-results/` 中。

| `server/mind.ts` | 性格、心情、兴趣、个人愿望、经历检索和反思机会 |
| `server/life-store.ts` | 生活记忆的原子持久化与旧记录迁移 |
| `src/MindPanel.tsx` | 内心、生活随记、愿望进度与记忆管理 |
| `src/scene.ts` | Three.js 家园、机器人动画、射线选择与相机 |
| `src/App.tsx` | 对话、思考、记忆与家园控制界面 |

| `tests/` | 独立于真实 API 额度的契约和行为验证 |

## Demo 范围

这是**单进程、本机共享世界**，默认只绑定 `127.0.0.1`。多个标签页观察和控制同一个 Milo；当前没有用户账户或多租户隔离。不应直接作为公网托管产品开放。

生活动作包含：喝水、吃饭、休息、睡觉、阅读、工作、浇水、清洗餐具。它们具有寻路、执行时长和实际状态效果，动画是程序化表现，不是物理抓取或骨骼动作生成。时间、天气和需求数值都是模拟数据。

生活记录分别保存在 `data/life-demo.json` 和 `data/life-live.json`，包括性格、兴趣、愿望进度、经历、随记、偏好及主动分享设置。旧 `memories-*.json` 首次迁入且保持原文件；新记录存在后不会回退重读旧文件。记录损坏时拒绝启动，避免静默重建人格覆盖历史。身体与场景状态重启后重新开始；这不是模型权重训练或自动生成新工具。

本地规则只理解有限的中英文生活关键词、简单顺序、停止和少量计划触发词；不能用于评估开放式自然语言理解。真实模型质量、延迟、置信度阈值和调用成本需要使用实际密钥做进一步评测。没有真实调用的情况下，界面中的 Jev/LLM 请求次数保持为 0。

更详细的运行时约束见 [架构说明](docs/architecture.md)。

自主行动与固定节奏的真实验证见 [调度修复记录](../../docs/runtime-cadence.md)。`pnpm test:live` 增加无用户指令的自主生活与需求耗尽恢复测试；这些测试使用真实密钥和有上限的请求预算。

真实接口与浏览器联调记录见 [真实模型接入](../../docs/live-integration.md)。

人格、反思与连续记忆的实现见 [生活记忆说明](../../docs/inner-life.md)。自主慢思考至少间隔 90 秒真实时间，仍需 Jev 选择；世界倍速和重置不能加快这一频率。
